2. Service:
 주제: Fetch API와 MockAPI를 기반으로 하는 음반 관리 CRUD프로그램 
 Field: 음반 이름, 작곡가 이름, 분야, 음반 매입날짜, 매입자로 구성된다.
 CRUD 기능: 매입한 음반을 등록할 수 있고, 매입했던 음반들이 뭔지 보여주고, 음반 정보를 수정하거나 삭제할 수 있고, 검색으로 원하는 음반을 찾을 수도 있다.

3. Key Learning:
   fetch()자바스크립트에서 서버에 요청을 보내고 응답을 받아오는 함수이다. 주소와 여러 옵션(GET, PUT, POST, DELETE)를 통해 정보를 가져오고 등록하고 삭제할 수 있다.
   JSON: 수업시간에 배웠듯이 서버와 브라우저 사이에서 자바스크립트의 배열과 객체를 직접 주고 받을 수 없기 때문에 데이터들을 서버가 인식할 수 있게 글자로 바꾸는 그 방식이다.
   async/await: 수업시간에 배웠듯이 fetch를 하자마자 서버에서 바로 응답이 오는 게 아니기 때문에 서버에서 응답이 올 때까지 기다리기 위해서 사용하고 그동안 브라우저 화면은 멈추지 않고 계속 작동한다.
   REST API: 주소로 데이터를 받아올 서버를 가리키고 옵션을 통해서 할 일을 하고 데이터를 JSON으로 주고 받는 과정이다.
   
4. AI / Search Usage: 사실 html이랑 css는 저번 과제를 거의 동일하게 진행했다. 그리고 html 구현 부분에 있어서도 저번 과제 썼던 알고리즘을 조금만 조금만 수정하면 되는 부분이어서 이번 과제는 쉬웠다고 생각한다.
   다만 API 이용하는 게 이번 주에 처음 배운 거다 보니 array에서 API로 코드를 수정하는 데에 많은 시간을 할애했다. 수업자료에 사실 거의 정답이 있어서 중간에 과제하다가 잘 모르겠어서 예제 먼저 하고 과제를
   마무리했다. 예제하고 나서도 이해 안 되는 부분, 정말 완벽하게 한 거 같은데 오타가 있어서 안 되는 거 같은 부분들 도움을 받았다. 이번 과제는 내가 70% ai가 한 30% 정도 한 거 같아. 코드 자체만 보면 거의 스스로 했지만
   잘 모르겠는 부분 이해시켜주고, 오류 찾아준 게 큰 역할을 한 거 같다.
   
5. Problem & Solution / Reflection: 검색기능 구현하는 데 잘 모르겠어서 구현하는 데 필요한 trim, includes, toLowerCase등을 배웠다. 이번 과제를 사실 그냥 저번 과제 복붙하고 시작하려다가 연습할 겸 처음부터 다 다시 해봤다.
   그래서 처음부터 지금까지의 흐름을 한 번 더 정리할 수 있었던 거 같아서 좋은 시간이었다. 서버까지 통신해서 데이터를 다룰 수 있으니 이제 뭔가 진짜 프로그램다운 프로그램을 다루는 느낌이다.
